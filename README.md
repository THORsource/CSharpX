# CSharpX

CSharpX ist ein experimentelles Sprachprojekt mit C#-ähnlicher Syntax und Rust-Codegenerierung für native Programme. Desktop-.NET-Interop, Embedded-Targets und Visual Studio 2022 gehören zum Zielumfang.

Öffne in Codex den entpackten Ordner `CSharpX`, der diese Datei, `AGENTS.md` und `Cargo.toml` enthält. `CODEX-START.md` enthält die Startanweisung. `IMPLEMENTATION_STATUS.md` enthält die frisch geprüfte Ausgangslage, `BUILD-TEST.md` die ausführbaren Prüfpfade. Das ursprüngliche README und die ursprüngliche Roadmap liegen unter `docs/import/`. Die fachlichen Detailentwürfe sind unter `docs/spec/` erhalten.

## Einstieg im Browser

[Mehrsprachiger CSharpX-Einstieg](HTML/index.html) mit Installation, erstem Projekt und Sprachbeispielen. Die HTML-Datei kann direkt im Browser geöffnet werden.

## Installation unter Windows

Starte per Doppelklick **Install-CSharpX.bat**. Der Assistent prüft die Voraussetzungen, baut Compiler und Erweiterung und fragt vor der Installation nach. Details stehen in [der Windows-Anleitung](BUILD-WINDOWS.md).
