# LINQ in CSharpX

Öffne Linq.csxproj in Visual Studio und erstelle das Projekt. Das Beispiel gibt 30 und 3 aus. Es unterstützt Enumerable.Range(start, count), Where mit einer Ganzzahlvergleichsoperation, Select mit einem Ganzzahlausdruck und Count() oder Sum() als abschließenden Operator. Lambdas können vorher deklarierte Ganzzahlen lesen. Die Abfrage wird beim Aggregieren als Schleife ausgeführt und benötigt keine Zwischenliste.

Die Syntax bildet einen Ausschnitt von LINQ to Objects ab. Allgemeine Sequenzwerte, Arrays als Quelle, Query-Syntax, IQueryables, andere LINQ-Operatoren und vollständige .NET-Ganzzahlsemantik gehören noch nicht zu diesem Umfang.
