# Arrays in CSharpX

Öffne Arrays.csxproj in Visual Studio 2022 und baue es in Debug. Das Beispiel zeigt explizite und abgeleitete Elementtypen, Initialisierungslisten, Standardwerte, Length sowie Lesen und Schreiben per Index. Die Zuweisung int[] alias = values teilt die Arraydaten. Eine Änderung über alias ist anschließend in values sichtbar.

Unterstützt sind eindimensionale Arrays der eingebauten Wert- und Stringtypen. Strings brauchen einen Initialisierer, da nullable String-Werte noch fehlen. Mehrdimensionale und verschachtelte Arrays, Arrays von Benutzerklassen sowie LINQ über Arrays sind offen. Ungültige Indizes und Längen werden zur Laufzeit gemeldet.
